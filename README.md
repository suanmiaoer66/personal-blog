# 林予 · 个人博客

这是参考 Wix 3698 模板的暖色与留白，以及用户提供的黑色联络表单截图制作的独立中文个人网站。它不依赖 Wix 账号或服务。

## 打开方式

直接用浏览器打开 `index.html` 即可使用。也可以在本目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

随后打开 http://127.0.0.1:4173 。网站使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 页面内容

- 个人介绍、兴趣和基本信息
- 工作、实习经历及学历时间线
- 三个可分类筛选、可展开详情的项目
- 三篇可分类筛选、可阅读全文的随笔
- 黑色联络区，包含姓名、邮箱、电话、留言与地址
- 移动端导航、键盘可操作的弹窗、减少动画偏好支持
- 滚动渐入、卡片错落入场、桌面首页渐出与轻微照片视差、顶部阅读进度线
- 各模块连同背景色整体淡入，正文在模块内继续分层入场

## 滚动动画

`motion.js` 和 `motion.css` 独立控制动效，不需要外部动画库。页面内容默认可见，动画仅在脚本成功运行且系统没有开启“减少动态效果”时启用。

正文与卡片进入视窗时轻轻上移并渐入，完全离屏后重置，再次滚回时重新入场。桌面首页随离开视窗渐淡，照片与圆形徽章有轻微位移和旋转；手机端保留较短距离的渐入，关闭首页视差和渐出。键盘聚焦和表单校验会即时显示对应内容，筛选卡片后会重新计算顺序。顶部细线展示阅读进度。

关于、经历、项目、随笔、寄语和联络模块会连同背景色整体淡入，持续约 0.85 秒；模块本身不位移，保持相邻背景之间的布局稳定。完全离屏后可再次触发，聚焦模块内控件时立即显示背景和内容。

可在 `motion.css` 调整动画时长和位移，在 `motion.js` 的 `updateDelays()` 调整错落间隔。

当前入场位移为桌面正文 72px、标题 88px、卡片 100px、首页照片 110px；手机为 44–64px。项目与文章卡片每隔 0.35 秒依次入场（延迟分别为 0、0.35、0.7 秒），渐入持续 0.9 秒、位移持续 1.1 秒。筛选后按剩余卡片的顺序重新排列延迟；其他内容保持原有节奏。

## 替换个人资料

当前姓名、院校、履历、项目、文章和地址都是设计示例，不代表真实用户信息。人像为 Unsplash 示例照片。

- 在 `index.html` 中修改个人信息、学历、经历、项目和文章摘要、邮箱、地址、网页标题及描述。
- 在 `app.js` 的 `projects` 与 `articles` 中修改详情正文，并同步摘要信息。
- 在 `assets/` 中替换照片与作品封面，或修改 HTML 中的图片路径及替代文本。
- 在 `styles.css` 顶部的 CSS 变量中调整主题颜色与字体。
- 完成真实资料替换后，更新页脚及地址旁的示例说明。

## 联络表单

默认是演示模式。表单会检查必填信息和邮箱格式，但不会发送或持久保存任何留言，也不会伪称发送成功。示例邮箱 `hello@linyu.example` 不能用于收信。

如需正式收信，在 `site-config.js` 中把 `contactEndpoint` 改为你已部署的 HTTPS 留言接口。它需要接受 JSON POST，字段为 `firstName`、`lastName`、`email`、`phone` 和 `message`，成功时返回 2xx 状态码。可以对接兼容 JSON 的表单服务，或自己的后端；跨域服务需要正确设置 CORS。页面已包含发送中、成功、失败及超时状态，失败会保留输入。

接口服务负责校验、反垃圾和邮件投递；不要在前端文件中放置邮件服务密钥。真实邮件投递尚未配置或验证。
